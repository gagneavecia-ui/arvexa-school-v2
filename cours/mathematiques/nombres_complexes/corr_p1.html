01

Forme algébrique : lire et écrire

N° 1 → 5

Reconnaître Re(z) et Im(z) après (et seulement après) simplification — le réflexe n° 0 du chapitre.

N° 1★

Donner la partie réelle et la partie imaginaire de : z₁ = 12 − 5i · z₂ = −(2/3)i · z₃ = √2 · z₄ = −7 + i

Calcul détaillé : on lit directement sur la forme a + ib : z₁ = 12 + (−5)i → Re = 12, Im = −5.

z₂ = 0 + (−2/3)i → Re = 0, Im = −2/3. z₃ = √2 + 0i → Re = √2, Im = 0. z₄ = −7 + 1i → Re = −7, Im = 1.

✅ Re(z₁) = 12, Im(z₁) = −5 ; Re(z₂) = 0, Im(z₂) = −2/3 ; Re(z₃) = √2, Im(z₃) = 0 ; Re(z₄) = −7, Im(z₄) = 1.

N° 2★

Écrire sous forme algébrique : a) (3 + 2i) + (5 − 7i)    b) (4 − i) − (6 + 3i)    c) 2(1 + i) − 3(2 − i)

Méthode : on regroupe les parties réelles entre elles et les parties imaginaires entre elles.

Calcul détaillé : a) (3 + 5) + (2 − 7)i = 8 − 5i

b) (4 − 6) + (−1 − 3)i = −2 − 4i

c) 2 + 2i − 6 + 3i = (2 − 6) + (2 + 3)i = −4 + 5i

✅ a) 8 − 5i   b) −2 − 4i   c) −4 + 5i

N° 3★

Écrire sous forme algébrique : a) i(4 + 9i)    b) −i(6 − 5i)    c) (1 + i)(1 − i) + 2i

Méthode : développer puis remplacer chaque i² par −1.

Calcul détaillé : a) i(4 + 9i) = 4i + 9i² = −9 + 4i

b) −i(6 − 5i) = −6i + 5i² = −5 − 6i

c) (1 + i)(1 − i) = 1 − i² = 2, donc 2 + 2i

✅ a) −9 + 4i   b) −5 − 6i   c) 2 + 2i

N° 4★★

Simplifier d'abord, puis donner Re et Im : z₁ = 3i² + 5 · z₂ = i³ + i · z₃ = 2i⁴ − 1 · z₄ = i⁵ − i

Méthode : règle d'or du cours — on ne lit Re et Im qu'après avoir tout simplifié.

Calcul détaillé : z₁ = −3 + 5 = 2 ; z₂ = −i + i = 0 ; z₃ = 2 − 1 = 1 ; z₄ = i − i = 0.

Conclusion : Re(z₁) = 2, Im(z₁) = 0 (réel pur) ; z₂ = 0 ; z₃ = 1 ; z₄ = 0.

✅ Piège réussi : les quatre nombres sont en réalité des réels !

N° 5★★

Soit z = (2 + 3i) + (a − i) où a est un réel. On sait que Re(z) = 5. Déterminer a, puis donner Im(z).

Données : z = (2 + 3i) + (a − i), a réel, Re(z) = 5. Objectif : trouver a puis Im(z).

Calcul détaillé : z = (2 + a) + (3 − 1)i = (2 + a) + 2i. Donc Re(z) = 2 + a = 5 → a = 3.

✅ a = 3 et Im(z) = 2 (la partie imaginaire ne dépend pas de a).

02

Puissances de i

N° 6 → 10

Cycle de période 4 : i, −1, −i, 1 — on réduit l'exposant avec le reste de la division euclidienne par 4.

N° 6★

Calculer : i²³ · i⁵⁰ · i⁷⁵ · i¹⁰¹

Méthode : iⁿ = i^(reste de n par 4).

Calcul détaillé : 23 = 4×5 + 3 → i²³ = i³ = −i ; 50 = 4×12 + 2 → i⁵⁰ = i² = −1 ; 75 = 4×18 + 3 → i⁷⁵ = −i ; 101 = 4×25 + 1 → i¹⁰¹ = i.

✅ i²³ = −i ; i⁵⁰ = −1 ; i⁷⁵ = −i ; i¹⁰¹ = i

N° 7★

Calculer : (5i)² · (−2i)⁴ · (−i)³

Méthode : on sépare le coefficient et le i : (ki)ⁿ = kⁿ iⁿ.

Calcul détaillé : (5i)² = 25i² = −25 ; (−2i)⁴ = 16i⁴ = 16 ; (−i)³ = (−i)² × (−i) = (−1)(−i) = i car (−i)² = i² = −1.

✅ −25 ; 16 ; i

N° 8★

Calculer : i¹⁸ + i¹⁹ + i²⁰ + i²¹   puis   i³² − i³⁰

Méthode : somme de 4 puissances consécutives de i = 0 (propriété du cours).

Calcul détaillé : 18, 19, 20, 21 sont consécutifs → la somme vaut 0 directement.

i³² = (i⁴)⁸ = 1 et i³⁰ = i²⁸ × i² = −1, donc i³² − i³⁰ = 1 − (−1) = 2.

✅ 0 et 2

N° 9★★

Calculer S = i + i² + i³ + … + i⁶⁰, puis S' = 1 + i + i² + … + i⁵⁰

Méthode : regrouper les termes par paquets de 4 consécutifs (chacun vaut 0).

Calcul détaillé : S : 60 = 4×15 termes → 15 paquets complets → S = 0.

S' : 51 termes. Les 48 premiers (i¹ → i⁴⁸) forment 12 paquets complets = 0. Il reste 1 + i⁴⁹ + i⁵⁰ = 1 + i + i² = 1 + i − 1 = i.

✅ S = 0 et S' = i

N° 10★★

Trouver tous les entiers n avec 0 ≤ n ≤ 12 tels que iⁿ soit un nombre réel.

Objectif : iⁿ réel ⟺ iⁿ vaut 1 ou −1 (jamais ±i).

Calcul détaillé : on teste les restes : reste 0 → 1 (réel) ; reste 1 → i (non) ; reste 2 → −1 (réel) ; reste 3 → −i (non). Donc iⁿ réel ⟺ n pair.

✅ n ∈ {0 ; 2 ; 4 ; 6 ; 8 ; 10 ; 12} — et iⁿ vaut 1 quand n est multiple de 4, −1 sinon.

03

Réel pur, imaginaire pur

N° 11 → 15

Réel pur ⟺ Im(z) = 0 · Imaginaire pur ⟺ Re(z) = 0 · 0 est les deux à la fois.

N° 11★

Classer chaque nombre : réel pur, imaginaire pur, ou ni l'un ni l'autre : z₁ = √5 · z₂ = √5 i · z₃ = 1 + √2 i · z₄ = i⁶ · z₅ = (1 + i)(1 − i)

Calcul détaillé : z₁ = √5 + 0i → réel pur ; z₂ = 0 + √5 i → imaginaire pur ; z₃ : les deux parties non nulles → ni l'un ni l'autre.

z₄ : i⁶ = i⁴ × i² = −1 → réel pur (simplifier d'abord !). z₅ : 1 − i² = 2 → réel pur.

✅ Réels purs : z₁, z₄, z₅ — imaginaire pur : z₂ — ni l'un ni l'autre : z₃.

N° 12★

Soit z = (x² + 1) + (x − 2)i avec x réel. Montrer que z n'est jamais imaginaire pur.

Objectif : montrer que Re(z) ne peut pas s'annuler.

Calcul détaillé : Re(z) = x² + 1. Or pour tout réel x, x² ≥ 0, donc x² + 1 ≥ 1 > 0 : la partie réelle est toujours strictement positive, jamais nulle.

✅ Conclusion : z n'est jamais imaginaire pur (quelle que soit la valeur de x).

N° 13★★

Déterminer x réel pour que z = x + (x² − 9)i soit : a) réel pur ; b) imaginaire pur. Donner z dans chaque cas.

Méthode : réel pur ⟺ Im(z) = 0 ; imaginaire pur ⟺ Re(z) = 0.

Calcul détaillé : a) x² − 9 = 0 ⟺ x = 3 ou x = −3 → z = 3 ou z = −3.

b) x = 0 → z = 0 + (0 − 9)i = −9i.

✅ Réel pur pour x = ±3 (z = ±3) ; imaginaire pur pour x = 0 (z = −9i).

N° 14★★

Soit z = (m + 1) + (m² − 1)i, m réel. a) Pour quel m est-il réel pur ? b) imaginaire pur ? c) Pour quel m a-t-on z = 0 ?

Calcul détaillé : a) réel pur ⟺ m² − 1 = 0 ⟺ m = 1 ou m = −1.

b) imaginaire pur ⟺ m + 1 = 0 ⟺ m = −1.

c) z = 0 ⟺ les DEUX conditions ⟺ m = −1 (on vérifie : z = 0 + 0i = 0 ✔).

✅ Réel pur : m = ±1 ; imaginaire pur : m = −1 ; z = 0 uniquement pour m = −1.

N° 15★★

Vrai ou faux ? Justifier chaque réponse. a) Im(3 + 5i) = 5i   b) 0 est à la fois réel pur et imaginaire pur   c) Si z est à la fois réel pur et imaginaire pur, alors z = 0.

Réponses argumentées : a) FAUX — Im(z) est un réel : Im(3 + 5i) = 5, pas 5i (piège classique du cours !).

b) VRAI — 0 vérifie Re(0) = 0 et Im(0) = 0 : il coche les deux définitions à la fois.

c) VRAI — réel pur donne Im(z) = 0 ; imaginaire pur donne Re(z) = 0 ; donc z = 0 + 0i = 0.

✅ a) Faux — b) Vrai — c) Vrai.

04

Premiers calculs : sommes et produits

N° 16 → 20

Développer, remplacer chaque i² par −1, regrouper — et repérer le schéma précieux (a + ib)(a − ib) = a² + b².

N° 16★

Calculer : a) (1 + i)(2 + 3i)    b) (3 − 2i)(3 + 2i)    c) (2 − i)(1 + 3i)

Calcul détaillé : a) 2 + 3i + 2i + 3i² = 2 + 5i − 3 = −1 + 5i

b) schéma (a − ib)(a + ib) : 3² + 2² = 13

c) 2 + 6i − i − 3i² = 2 + 5i + 3 = 5 + 5i

✅ a) −1 + 5i   b) 13 (réel !)   c) 5 + 5i

N° 17★

Calculer (2 + i)³.

Méthode : passer par le carré : (2 + i)³ = (2 + i)² × (2 + i).

Calcul détaillé : (2 + i)² = 4 + 4i + i² = 3 + 4i. Puis (3 + 4i)(2 + i) = 6 + 3i + 8i + 4i² = 6 + 11i − 4 = 2 + 11i.

✅ (2 + i)³ = 2 + 11i

N° 18★

Développer et réduire (x + iy)(3 + 2i) pour x, y réels.

Calcul détaillé : 3x + 2ix + 3iy + 2i²y = 3x + 2xi + 3yi − 2y.

On regroupe : partie réelle 3x − 2y, partie imaginaire 2x + 3y.

✅ (x + iy)(3 + 2i) = (3x − 2y) + i(2x + 3y)

N° 19★★

Calculer (1 + i)⁴, puis en déduire (1 + i)⁸.

Calcul détaillé : (1 + i)² = 1 + 2i + i² = 2i. Donc (1 + i)⁴ = (2i)² = 4i² = −4.

Et (1 + i)⁸ = [(1 + i)⁴]² = (−4)² = 16.

✅ (1 + i)⁴ = −4 et (1 + i)⁸ = 16

N° 20★★

Montrer que pour tous réels a, b : (a + ib)(a − ib) = a² + b², puis appliquer ce schéma pour calculer (2√2 − i√3)(2√2 + i√3).

Calcul détaillé : (a + ib)(a − ib) = a² − abi + abi − i²b² = a² − i²b² = a² + b².

Application : a = 2√2, b = √3 → (2√2)² + (√3)² = 8 + 3 = 11.

✅ Le produit vaut 11 : un réel strictement positif, comme toujours avec ce schéma.

05

Identités remarquables revisitées

N° 21 → 25

(a + ib)² = (a² − b²) + 2iab — développer d'abord, remplacer chaque i² ensuite.

N° 21★

Développer avec l'identité du cours : (3 + 2i)² · (1 − 4i)² · (−2 + i)²

Calcul détaillé : (3 + 2i)² = 9 + 12i + 4i² = 5 + 12i

(1 − 4i)² = 1 − 8i + 16i² = −15 − 8i

(−2 + i)² = 4 − 4i + i² = 3 − 4i

✅ 5 + 12i ; −15 − 8i ; 3 − 4i

N° 22★

Écrire sous forme algébrique : (1 + i)² + (1 − i)².

Calcul détaillé : (1 + i)² = 2i et (1 − i)² = −2i.

Somme : 2i + (−2i) = 0.

✅ Le résultat est 0 — la somme des deux carrés est réelle (nulle ici).

N° 23★★

Calculer z = (2 + i)² − (2 − i)². Que remarque-t-on ? Vérifier la remarque sur (1 + 3i)² − (1 − 3i)².

Calcul détaillé : (2 + i)² = 3 + 4i et (2 − i)² = 3 − 4i, donc z = (3 + 4i) − (3 − 4i) = 8i.

Remarque : z est imaginaire pur. Vérification : (1 + 3i)² − (1 − 3i)² = (−8 + 6i) − (−8 − 6i) = 12i — encore imaginaire pur ✔.

Pourquoi : (a + ib)² − (a − ib)² = 4abi — toujours imaginaire pur.

✅ z = 8i, et la différence des deux carrés est toujours imaginaire pure.

N° 24★★

Résoudre dans ℂ : z² = 3 + 4i. (Indice : cherche un nombre de la forme a + ib dont le carré redonne exactement 3 + 4i.)

Méthode : on cherche a, b réels avec a² − b² = 3 et 2ab = 4, c'est-à-dire ab = 2.

Calcul détaillé : on essaie (a, b) = (2, 1) : ab = 2 ✔ et a² − b² = 4 − 1 = 3 ✔. Donc (2 + i)² = 3 + 4i.

Un carré a toujours DEUX solutions opposées : z = 2 + i ou z = −(2 + i) = −2 − i.

✅ z = 2 + i ou z = −2 − i

N° 25★★

Pour quels réels a et b le nombre (a + ib)² est-il réel pur ? Interpréter géométriquement les deux cas.

Calcul détaillé : (a + ib)² = (a² − b²) + 2abi. Réel pur ⟺ 2ab = 0 ⟺ a = 0 ou b = 0.

Interprétation : si b = 0, z était déjà réel (z² = a² ≥ 0). Si a = 0, z = ib est imaginaire pur et z² = −b² ≤ 0 : le carré d'un imaginaire pur est un réel négatif ou nul.

✅ (a + ib)² réel pur ⟺ a = 0 ou b = 0 — et dans le cas a = 0, le carré est ≤ 0.

06

Égalité : identification directe

N° 26 → 30

a + ib = a' + ib' ⟺ a = a' ET b = b' — une équation complexe donne DEUX équations réelles.

N° 26★

Déterminer les réels x et y tels que (2x + 5) + (3y − 1)i = 11 + 8i.

Méthode : réel = réel ET imaginaire = imaginaire.

Calcul détaillé : 2x + 5 = 11 → 2x = 6 → x = 3 ; 3y − 1 = 8 → 3y = 9 → y = 3.

Vérification : (2×3 + 5) + (3×3 − 1)i = 11 + 8i ✔

✅ x = 3 et y = 3

N° 27★

Déterminer les réels x et y tels que (x² + 3) + (2y + 1)i = 12 + 7i. Combien de couples trouves-tu ?

Calcul détaillé : x² + 3 = 12 → x² = 9 → x = 3 ou x = −3 ; 2y + 1 = 7 → y = 3.

Conclusion : deux couples possibles, car la première équation est du second degré.

✅ (x, y) = (3 ; 3) ou (−3 ; 3)

N° 28★★

Déterminer les réels x et y tels que (x + y) + (x − y)i = 4 + 2i.

Calcul détaillé : x + y = 4 et x − y = 2. On additionne : 2x = 6 → x = 3, puis y = 4 − 3 = 1.

Vérification : (3 + 1) + (3 − 1)i = 4 + 2i ✔

✅ x = 3 et y = 1

N° 29★★

Déterminer les réels x et y tels que (2x − y) + (x + 2y)i = −1 + 5i.

Calcul détaillé : 2x − y = −1 et x + 2y = 5. De la première : y = 2x + 1.

Dans la seconde : x + 4x + 2 = 5 → 5x = 3 → x = 3/5, puis y = 6/5 + 1 = 11/5.

Vérification : 2(3/5) − 11/5 = −1 ✔ et 3/5 + 2(11/5) = 25/5 = 5 ✔

✅ x = 3/5 et y = 11/5

N° 30★★

Trouver tous les couples (x, y) tels que (x + y) + (x − y)i = 0. Quelle propriété du cours retrouve-t-on ici ?

Calcul détaillé : x + y = 0 et x − y = 0. En additionnant : 2x = 0 → x = 0, puis y = 0.

Propriété : z = 0 ⟺ Re(z) = 0 ET Im(z) = 0 — les deux conditions à la fois.

✅ Seul le couple (0 ; 0) convient.

07

Équations (α + iβ) z = γ + iδ

N° 31 → 35

Le réflexe n° 1 du chapitre : poser z = x + iy, développer, identifier, résoudre le système 2 × 2, vérifier.

N° 31★★

Résoudre dans ℂ : (2 + i)z = 7 + i.

Calcul détaillé : on pose z = x + iy : (2 + i)(x + iy) = (2x − y) + i(x + 2y) = 7 + i.

Système : 2x − y = 7 et x + 2y = 1. De la première : y = 2x − 7. Report : x + 4x − 14 = 1 → 5x = 15 → x = 3, puis y = −1.

Vérification : (2 + i)(3 − i) = 6 − 2i + 3i − i² = 7 + i ✔

✅ z = 3 − i

N° 32★★

Résoudre dans ℂ : (1 + 2i)z = 5.

Attention : 5 = 5 + 0i — la partie imaginaire de droite est nulle !

Calcul détaillé : (1 + 2i)(x + iy) = (x − 2y) + i(2x + y). Système : x − 2y = 5 et 2x + y = 0.

De la seconde : y = −2x. Report : x + 4x = 5 → x = 1, puis y = −2.

Vérification : (1 + 2i)(1 − 2i) = 1 + 4 = 5 ✔ (schéma a² + b² !)

✅ z = 1 − 2i

N° 33★★

Résoudre dans ℂ : (3 − i)z = 10 − 5i. (Les fractions sont autorisées !)

Calcul détaillé : (3 − i)(x + iy) = (3x + y) + i(3y − x). Système : 3x + y = 10 et 3y − x = −5.

De la première : y = 10 − 3x. Report : 30 − 9x − x = −5 → −10x = −35 → x = 7/2, puis y = 10 − 21/2 = −1/2.

Vérification : (3 − i)(7/2 − i/2) = 21/2 − 3i/2 − 7i/2 + i²/2 = 10 − 5i ✔

✅ z = 7/2 − (1/2)i

N° 34★★

Résoudre dans ℂ : (2 + 3i)z = 5 + 14i.

Calcul détaillé : (2 + 3i)(x + iy) = (2x − 3y) + i(3x + 2y). Système : 2x − 3y = 5 et 3x + 2y = 14.

On combine : 2×(1re) → 4x − 6y = 10 ; 3×(2e) → 9x + 6y = 42. Addition : 13x = 52 → x = 4, puis 2y = 14 − 12 = 2 → y = 1.

Vérification : (2 + 3i)(4 + i) = 8 + 2i + 12i + 3i² = 5 + 14i ✔

✅ z = 4 + i

N° 35★★

Résoudre dans ℂ : iz = 3 − 4i.

Méthode : même réflexe, avec α = 0, β = 1 : poser z = x + iy.

Calcul détaillé : i(x + iy) = ix + i²y = −y + ix = 3 − 4i. Donc −y = 3 → y = −3 et x = −4.

Vérification : i(−4 − 3i) = −4i − 3i² = 3 − 4i ✔

✅ z = −4 − 3i

08

Carrés z² = k et analyse de systèmes

N° 36 → 40

L'identification complète : poser z = x + iy, développer z², identifier — et savoir lire l'issue du système.

N° 36★★

Résoudre dans ℂ : z² = −9.

Calcul détaillé : z² = (x² − y²) + 2xyi = −9 + 0i → x² − y² = −9 et 2xy = 0.

Si y = 0 : x² = −9 impossible dans ℝ. Donc x = 0 : −y² = −9 → y² = 9 → y = ±3.

Vérification : (3i)² = −9 ✔ et (−3i)² = −9 ✔

✅ z = 3i ou z = −3i — deux solutions opposées, comme pour tout x² = k négatif.

N° 37★★

Résoudre dans ℂ : z² = 8i.

Calcul détaillé : x² − y² = 0 et 2xy = 8, soit xy = 4 > 0 : x et y de même signe → y = x.

Alors 2x² = 8 → x² = 4 → x = ±2, et y = x.

Vérification : (2 + 2i)² = 4 + 8i + 4i² = 8i ✔

✅ z = 2 + 2i ou z = −2 − 2i

N° 38★★★

Résoudre dans ℂ : z² = −5i. (Les racines carrées sont autorisées dans la réponse finale.)

Calcul détaillé : x² − y² = 0 et 2xy = −5, soit xy = −5/2 < 0 : x et y de signes opposés → y = −x.

Alors 2x(−x) = −5 → −2x² = −5 → x² = 5/2, donc x = ±√(5/2) = ±√10/2, et y = −x.

Vérification : [(√10/2)(1 − i)]² = (10/4)(1 − 2i + i²) = (5/2)(−2i) = −5i ✔

✅ z = (√10/2)(1 − i) ou z = −(√10/2)(1 − i)

N° 39★★

Résoudre dans ℂ : (1 − i)z = 8 + 4i.

Calcul détaillé : (1 − i)(x + iy) = x + iy − ix − i²y = (x + y) + i(y − x). Système : x + y = 8 et y − x = 4.

Addition : 2y = 12 → y = 6, puis x = 2.

Vérification : (1 − i)(2 + 6i) = 2 + 6i − 2i − 6i² = 8 + 4i ✔

✅ z = 2 + 6i

N° 40★★

Analyse : on cherche (x, y) vérifiant à la fois x − y = 2 et 2x − 2y = 5. Montrer qu'aucun couple ne convient, et expliquer ce que cela signifierait pour une équation complexe qui produirait ce système.

Calcul détaillé : en multipliant la première par 2 : 2x − 2y = 4. Mais la seconde exige 2x − 2y = 5 : contradiction (4 ≠ 5).

Interprétation : les deux droites sont strictement parallèles — aucun point d'intersection. Une équation complexe dont l'identification mène à ce système n'a donc aucune solution.

✅ Aucune solution — le système 2 × 2 peut être impossible, comme annoncé dans le cours.

09

Paramètre m : classification et égalité

N° 41 → 45

Quand les parties dépendent d'un réel m, chaque condition (réel pur, imaginaire pur, égalité) devient une équation en m.

N° 41★★

Soit z = (m − 3) + (2m + 1)i, m réel. a) Pour quel m est-il réel pur ? b) imaginaire pur ? c) Calculer z pour m = 3.

Calcul détaillé : a) réel pur ⟺ 2m + 1 = 0 ⟺ m = −1/2 (on obtient alors z = −7/2).

b) imaginaire pur ⟺ m − 3 = 0 ⟺ m = 3. c) pour m = 3 : z = 0 + 7i = 7i ✔

✅ Réel pur : m = −1/2 ; imaginaire pur : m = 3 ; z(3) = 7i.

N° 42★★

Soit z = (m² − 1) + (m + 1)i, m réel. a) Pour quel m est-il réel pur ? b) imaginaire pur ? c) Que vaut z dans le cas particulier où il est les deux à la fois ?

Calcul détaillé : a) réel pur ⟺ m + 1 = 0 ⟺ m = −1.

b) imaginaire pur ⟺ m² − 1 = 0 ⟺ m = 1 ou m = −1.

c) les deux à la fois ⟺ m = −1, et alors z = (1 − 1) + 0i = 0 — le célèbre cas de 0, seul nombre classé des deux côtés !

✅ Réel pur : m = −1 ; imaginaire pur : m = ±1 ; les deux à la fois : m = −1, avec z = 0.

N° 43★★

Existe-t-il un réel m tel que (2m + 1) + (3m − 2)i = 5 − i ? Justifier soigneusement.

Calcul détaillé : partie réelle : 2m + 1 = 5 → m = 2. Partie imaginaire : 3m − 2 = −1 → 3m = 1 → m = 1/3.

Il faudrait m = 2 ET m = 1/3 en même temps : impossible. Un seul paramètre ne peut pas satisfaire deux exigences contradictoires.

✅ Aucun m ne convient — l'égalité est impossible pour tout m.

N° 44★★★

Soit z = (m² − 2m + 1) + (m² + m − 2)i. a) Factoriser les deux coefficients. b) Pour quels m est-il réel pur ? c) imaginaire pur ? d) Que se passe-t-il pour m = 1 ?

Factorisation : m² − 2m + 1 = (m − 1)² et m² + m − 2 = (m + 2)(m − 1), donc z = (m − 1)² + (m + 2)(m − 1)i.

Calcul détaillé : b) réel pur ⟺ (m + 2)(m − 1) = 0 ⟺ m = −2 ou m = 1.

c) imaginaire pur ⟺ (m − 1)² = 0 ⟺ m = 1.

d) pour m = 1 : z = 0 + 0i = 0 — à la fois réel pur et imaginaire pur. Pour m = −2 : z = 9 + 0i = 9, réel pur non nul.

✅ Réel pur : m ∈ {−2 ; 1} ; imaginaire pur : m = 1 ; m = 1 donne z = 0.

N° 45★★

Soit z = (2m − 1) + (m + 2)i et w = (m + 4) + (2m − 3)i, m réel. Déterminer m pour que z = w, puis vérifier.

Calcul détaillé : égalité des parties réelles : 2m − 1 = m + 4 → m = 5.

Égalité des parties imaginaires : m + 2 = 2m − 3 → m = 5. Les deux conditions donnent la MÊME valeur : c'est compatible !

Vérification : pour m = 5 : z = 9 + 7i et w = 9 + 7i ✔

✅ z = w pour m = 5 (les deux équations « votent » pour la même valeur).

N° 46★★

Vrai ou faux ? Justifier chaque affirmation. a) i⁴⁸ + i⁴⁹ = 1 + i   b) Im(7 − 3i) = −3i   c) (1 + i)² est imaginaire pur   d) Si z est imaginaire pur, alors z² est réel   e) 2 + 3i = 3 + 2i

Réponses argumentées : a) VRAI — i⁴⁸ = (i⁴)¹² = 1 et i⁴⁹ = i.

b) FAUX — Im(7 − 3i) = −3, un réel (jamais de i dans une partie imaginaire !).

c) VRAI — (1 + i)² = 2i, et Re(2i) = 0.

d) VRAI — si z = ib, alors z² = i²b² = −b², réel (négatif ou nul).

e) FAUX — 2 ≠ 3 : une seule partie diffère, et cela suffit pour z ≠ z'.

✅ a) Vrai — b) Faux — c) Vrai — d) Vrai — e) Faux.

N° 47★★★

Défi — Calculer (1 + i)⁴⁴ en s'appuyant sur (1 + i)² = 2i.

Méthode : écrire la puissance en fonction de carrés successifs.

Calcul détaillé : (1 + i)⁴⁴ = [(1 + i)²]²² = (2i)²² = 2²² × i²².

Or i²² = i²⁰ × i² = 1 × (−1) = −1. Donc (1 + i)⁴⁴ = −2²².

✅ (1 + i)⁴⁴ = −2²² = −4 194 304 — un réel strictement négatif, logique : (1 + i)² = 2i est imaginaire pur, et le carré d'un imaginaire pur est réel négatif (N° 46-d) !

N° 48★★★

Défi — Sans tout développer, montrer que A = (2 + i)(2 − i)(3 + i)(3 − i) est un entier, puis calculer A.

Méthode : regrouper par paires (a + ib)(a − ib) = a² + b².

Calcul détaillé : (2 + i)(2 − i) = 2² + 1² = 5 et (3 + i)(3 − i) = 3² + 1² = 10.

Donc A = 5 × 10 = 50.

✅ A = 50 — le schéma précieux transforme le produit en entiers avant même de développer !

N° 49★★★

Défi — Résoudre dans ℂ : (x + iy)(1 − i) = (1 + i)(2 + 3i).

Étape 1 — Simplifier la droite : (1 + i)(2 + 3i) = 2 + 3i + 2i + 3i² = −1 + 5i.

Étape 2 — Développer la gauche : (x + iy)(1 − i) = x − ix + iy − i²y = (x + y) + i(y − x).

Étape 3 — Identifier : x + y = −1 et y − x = 5. Addition : 2y = 4 → y = 2, puis x = −3.

Vérification : (−3 + 2i)(1 − i) = −3 + 3i + 2i − 2i² = −1 + 5i ✔

✅ z = −3 + 2i

N° 50★★★

Grand défi final — Soit z = x + iy (x, y réels) et w = z² + 2z. a) Montrer que Re(w) = x² − y² + 2x et Im(w) = 2xy + 2y. b) Déterminer tous les z pour lesquels w est réel pur.

a) Calcul détaillé : z² = (x² − y²) + 2xyi et 2z = 2x + 2yi, donc w = (x² − y² + 2x) + i(2xy + 2y) ✔

b) Calcul détaillé : w réel pur ⟺ Im(w) = 0 ⟺ 2xy + 2y = 0 ⟺ 2y(x + 1) = 0 ⟺ y = 0 ou x = −1.

Interprétation : y = 0 → z est un réel quelconque ; x = −1 → z = −1 + iy, tous les nombres d'abscisse −1.

✅ w est réel pur ⟺ y = 0 (z réel) ou x = −1 (z = −1 + iy).
