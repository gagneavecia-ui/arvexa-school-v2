Motivation

Pourquoi les nombres complexes ?

Commençons par une question toute simple : existe-t-il un nombre dont le carré vaut −1 ? Faisons l'inventaire. Un nombre positif au carré donne un positif (3² = 9). Un nombre négatif au carré donne… aussi un positif ((−3)² = 9, le signe − disparaît). Et zéro donne zéro. Conclusion :

Le mur

Aucun nombre réel n'a un carré négatif. L'équation x² = −1 n'a aucune solution dans ℝ. Il en va de même pour toutes les équations x² = k avec k < 0.

Visualisons ce problème sur la droite des réels. Pour x² = 4, on trouve x = 2 et x = −2 : deux points bien présents sur la droite. Mais pour x² = −1, la droite est « trouée » : aucun point ne convient.

Face à ce mur, deux options : renoncer, ou inventer. L'histoire a choisi d'inventer — et ce n'est pas la première fois ! Les nombres négatifs ont longtemps paru absurdes (« comment avoir −3 moutons ? »). Les irrationnels comme √2 ont scandalisé les Grecs. À chaque fois, élargir la notion de nombre a résolu des problèmes jusque-là insolubles.

L'idée géniale

On décide d'inventer un nouveau nombre, noté i, et on lui attribue par convention la propriété manquante :

i² = −1

Ce nombre s'appelle l'unité imaginaire. Ce n'est pas un réel : c'est un objet nouveau, créé exprès pour combler le trou de la droite. La seule règle du jeu : il obéit aux mêmes lois de calcul que les réels (addition, multiplication, distributivité…), avec cette seule propriété supplémentaire i² = −1.

Conséquence immédiate : x² = −1 possède désormais deux solutions, x = i et x = −i (vérifie : (−i)² = i² = −1 ✔). Et mieux : on montrera plus loin que toute équation polynomiale devient résoluble — c'est le théorème fondamental de l'algèbre.

Où rencontre-t-on les complexes ?
  • Électricité : impédances et courants alternatifs
  • Mécanique quantique : la fonction d'onde est complexe
  • Traitement du signal : analyse de Fourier, compression MP3, JPEG
  • Télécommunications : WiFi, 4G, 5G
  • Imagerie médicale : reconstruction des images d'IRM
✏️ Exercice d'application 1 — Solutions dans ℝ ou dans ℂ ?

Énoncé : parmi les équations suivantes, lesquelles ont des solutions dans ℝ ? Lesquelles en ont dans ℂ ? Donne-les quand elles existent.

a) x² = 16    b) x² + 1 = 0    c) x² − 3x = 0    d) x² = −9

Voir la solution détaillée

a) x² = 16. 4² = 16 et (−4)² = 16. Deux solutions dans ℝ : x = 4 ou x = −4 ✔

b) x² + 1 = 0, c'est-à-dire x² = −1. Carré négatif impossible dans ℝ → aucune solution dans ℝ. Dans ℂ : par définition de i, x = i ou x = −i ✔

c) x² − 3x = 0. On factorise : x(x − 3) = 0. Un produit est nul si un facteur est nul : x = 0 ou x = 3. Deux solutions dans ℝ ✔

d) x² = −9. Aucune solution dans ℝ. Dans ℂ : on remarque que −9 = 9 × (−1) = 9i² = (3i)². Donc x = 3i ou x = −3i ✔

Bilan : dès qu'un carré doit valoir un nombre négatif, ℝ échoue et ℂ réussit — toujours avec deux solutions opposées.

Un peu d'histoire

À leurs débuts, ces nombres sont appelés « impossibles » ou « fictifs ». Descartes forge l'expression « nombres imaginaires » avec une nuance méprisante — et le nom est resté. Euler introduit la lettre i en 1777, et Gauss leur donne leurs lettres de noblesse avec leur interprétation géométrique. Ironie : ce sont les équations de degré 3 (Bombelli, 1572) qui ont révélé leur utilité — des nombres « fictifs » qui produisaient des résultats parfaitement réels !

Notion 1 · forme_algebrique

Le nombre i et ses puissances

Avant d'écrire des nombres complexes, il faut bien connaître l'ingrédient de base : le nombre i, défini par i² = −1. Que se passe-t-il si on le multiplie par lui-même encore et encore ? Chaque ligne se déduit de la précédente :

La construction du cycle, ligne par ligne

i¹ = i  (par définition)

i² = −1  (la propriété fondatrice)

i³ = i² × i = (−1) × i = −i

i⁴ = i³ × i = (−i) × i = −i² = −(−1) = 1

i⁵ = i⁴ × i = 1 × i = i  ← le cycle recommence !

Les puissances de i tournent en boucle avec une périodicité de 4 : i, −1, −i, 1, puis encore i, −1, −i, 1…

Calculer iⁿ pour n'importe quel n : la méthode du reste

La roue fait un tour complet tous les 4 pas. Multiplier par i⁴ = 1 ne change rien : seuls comptent les pas excédentaires — c'est-à-dire le reste de la division de n par 4.

iⁿ = ir où r est le reste de n dans la division par 4
On écrit n = 4q + r avec r ∈ {0, 1, 2, 3}, puis iⁿ = (i⁴)ᵈ × iʳ = 1 × iʳ = iʳ.
  • Si n ≡ 0 (mod 4) → iⁿ = 1
  • Si n ≡ 1 (mod 4) → iⁿ = i
  • Si n ≡ 2 (mod 4) → iⁿ = −1
  • Si n ≡ 3 (mod 4) → iⁿ = −i
💡 Bonus : la somme magique

Additionne les quatre positions de la roue :

i + i² + i³ + i⁴ = i + (−1) + (−i) + 1 = 0

Toute somme de 4 puissances consécutives de i vaut zéro — les termes s'éteignent deux à deux. Très utile pour les sommes longues.

Erreur classique — à bannir définitivement

Ne jamais écrire i = √(−1). Ce n'est pas une question de style : c'est mathématiquement faux. Les règles de la racine carrée cessent d'être vraies sur les négatifs — les utiliser conduit à des absurdités :

−1 = i × i = √(−1) × √(−1) = √1 = 1 ?! — donc −1 = 1, absurde.

La formulation correcte est toujours : « i est le nombre tel que i² = −1 ».

✏️ Exercice d'application 2 — Manier les puissances de i

Énoncé : calculer i³⁷, i⁴⁸, (2i)³, puis S = i + i² + i³ + … + i²⁰²⁵

Voir la solution détaillée

i³⁷ : division euclidienne : 37 = 4 × 9 + 1 → reste 1 → i³⁷ = i¹ = i

i⁴⁸ : 48 = 4 × 12 + 0 → reste 0 → i⁴⁸ = 1

(2i)³ : on sépare le nombre et le i : (2i)³ = 2³ × i³ = 8 × (−i) = −8i

S : il y a 2025 = 4 × 506 + 1 termes. On regroupe 506 paquets de 4 termes consécutifs — chacun vaut 0 (somme magique !) — et il reste le dernier terme i²⁰²⁵ = i (reste 1).

✅ Conclusion : i³⁷ = i, i⁴⁸ = 1, (2i)³ = −8i, S = i

Notion 1 · forme_algebrique

L'écriture z = a + ib

Comment s'écrit un nombre complexe ? L'idée est simple : toute quantité contenant des i peut se ramener, après calcul, à une écriture « quelque chose + i fois quelque chose d'autre ». C'est la forme algébrique.

Forme algébrique
z = a + ib
avec a ∈ ℝ, b ∈ ℝ et i² = −1 — cette écriture est unique

Le mot unique est capital : un complexe donné possède une seule forme algébrique, tout comme un entier pair s'écrit de manière unique 2k. Garde cette unicité en tête : c'est elle qui justifiera la règle d'égalité de la Notion 2. Les deux notions de cette partie sont liées !

Conventions d'écriture (les usages qui évitent les malentendus)
  • Partie réelle d'abord : on écrit 3 + 5i, pas 5i + 3
  • On écrit 5i plutôt que i5 — et ib plutôt que bi (même si ib = bi)
  • Partie imaginaire négative : −3 − 2i plutôt que −3 + (−2)i

Vocabulaire : les deux « ingrédients » de z

Dans l'écriture z = a + ib, les deux réels a et b portent des noms précis qu'il faut connaître sur le bouton :

a
Partie réelle
Re(z) = a
b
Partie imaginaire
Im(z) = b
ℝ
Réel pur
Im(z) = 0
iℝ
Imaginaire pur
Re(z) = 0
Le piège n°1 du chapitre

La partie imaginaire de z = 3 + 5i est 5, et non 5i ! La partie imaginaire est toujours un nombre réel — c'est le coefficient qui multiplie i. De même, Re(z) et Im(z) sont des réels : Re(3 + 5i) = 3 et Im(3 + 5i) = 5.

z = Re(z) + i·Im(z)
Identité à connaître : un complexe se reconstitue à partir de ses deux parties.

Cas particuliers : lire la forme algébrique à la loupe

  • Réel pur : z = a + 0i = a. Exemples : 5, −3, √2, π. Le nombre 5 est un complexe — sa partie imaginaire vaut simplement zéro.
  • Imaginaire pur : z = 0 + ib = ib. Exemples : 3i, −i, 7i.
  • Le nombre 0 : à la fois réel pur et imaginaire pur — c'est le seul dans ce cas.
z ∈ ℝ ⟺ Im(z) = 0
Un complexe est réel si et seulement si sa partie imaginaire est nulle.
z ∈ iℝ ⟺ Re(z) = 0
Un complexe est imaginaire pur si et seulement si sa partie réelle est nulle.
✏️ Exercice d'application 3 — Lire Re et Im, classer

Énoncé : pour chaque nombre, donner Re(z) et Im(z), puis dire s'il est réel pur, imaginaire pur, ou ni l'un ni l'autre :

z₁ = 5 − 2i · z₂ = −7i · z₃ = 1/2 · z₄ = i² + 2i · z₅ = 0

Voir la solution détaillée

z₁ = 5 − 2i : directement lisible → Re(z₁) = 5, Im(z₁) = −2 (attention au signe !). Ni l'un ni l'autre.

z₂ = −7i : pas de partie réelle visible, donc elle vaut 0 → Re(z₂) = 0, Im(z₂) = −7. Imaginaire pur ✔

z₃ = 1/2 : Re(z₃) = 1/2, Im(z₃) = 0. Réel pur ✔

z₄ = i² + 2i : ⚠️ il faut d'abord simplifier ! Comme i² = −1 : z₄ = −1 + 2i. Donc Re(z₄) = −1, Im(z₄) = 2. Ni l'un ni l'autre.

z₅ = 0 : Re(z₅) = 0 et Im(z₅) = 0. À la fois réel pur ET imaginaire pur — le seul !

Règle d'or : on ne lit Re et Im qu'après avoir tout simplifié sous la forme a + ib.

Notion 1 · forme_algebrique

La forme algébrique en pratique

En exercice, on te donnera rarement z déjà écrit a + ib : il faudra transformer une expression (somme, produit, puissance…) pour la mettre sous forme algébrique. Voici les techniques, de la plus simple à la plus complète.

Technique 1 — Sommes et différences : ingrédient par ingrédient

(a + ib) ± (c + id) = (a ± c) + i(b ± d)
On regroupe les parties réelles entre elles, les parties imaginaires entre elles.
Exemple

(2 + 3i) + (5 − i) = (2 + 5) + i(3 − 1) = 7 + 2i

(2 + 3i) − (5 − i) = (2 − 5) + i(3 − (−1)) = −3 + 4i — attention : −(−i) = +i !

Technique 2 — Produits : développer puis remplacer i² par −1

On développe comme un produit de deux binômes classique (distributivité), puis chaque i² devient −1. Enfin, on regroupe réel / imaginaire.

Démonstration de la formule générale

(a + ib)(c + id)

= ac + iad + ibc + i²bd  (distributivité — double développement)

= ac + iad + ibc − bd  (car i² = −1)

= (ac − bd) + i(ad + bc)  (regroupement)

(a + ib)(c + id) = (ac − bd) + i(ad + bc)
En pratique, tu n'as pas besoin d'apprendre cette formule : tu développes et tu simplifies les i².
Exemples numériques

(2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i

(1 + i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i  ← un carré imaginaire pur, du jamais vu dans ℝ !

⭐ Le schéma à connaître par cœur

(a + ib)(a − ib) = a² + b² — le résultat est toujours un réel positif ! Les termes en i s'éteignent : a² − iab + iab − i²b² = a² + b².

Exemple : (3 + 2i)(3 − 2i) = 9 + 4 = 13. Ce schéma sera la clé des quotients plus loin dans le chapitre — mémorise-le maintenant !

Technique 3 — Puissances d'un complexe : multiplication répétée

Exemple détaillé

Soit z = 1 + i :

z² = (1 + i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i  (identité remarquable (a+b)²)

z³ = z² × z = 2i × (1 + i) = 2i + 2i² = −2 + 2i

z⁴ = z² × z² = 2i × 2i = 4i² = −4 — et hop, un réel !

✏️ Exercice d'application 4 — Mettre sous forme algébrique

Énoncé : écrire sous forme algébrique et donner Re et Im :

a) z = (2 + i) + 3i(2 − i)    b) w = (1 + i)² + (2 − i)(2 + i)

Voir la solution détaillée

a) D'abord le produit : 3i(2 − i) = 6i − 3i² = 6i + 3 = 3 + 6i. Puis la somme : z = (2 + 3) + i(1 + 6) = 5 + 7i. Donc Re(z) = 5, Im(z) = 7.

b) Premier terme (identité (a+b)²) : (1 + i)² = 1 + 2i + i² = 2i. Second terme (schéma (a+ib)(a−ib)) : (2 − i)(2 + i) = 2² + 1² = 5. Somme : w = 5 + 2i. Donc Re(w) = 5, Im(w) = 2.

Notion 2 · egalite_complexes

La règle d'égalité

Comment savoir si deux nombres complexes sont égaux ? La réponse s'appuie directement sur la Notion 1 : puisque la forme algébrique est unique, deux complexes égaux ont forcément la même écriture a + ib — donc les mêmes parties réelle et imaginaire.

Règle fondamentale d'égalité
a + ib = a' + ib' ⟺ a = a' ET b = b'

Autrement dit : deux nombres complexes sont égaux si et seulement si leurs parties réelles coïncident ET leurs parties imaginaires coïncident. Une seule égalité complexe équivaut à deux égalités réelles. C'est cette bascule — du complexe vers le réel — qui transforme les équations en systèmes : c'est l'outil le plus utilisé de tout le chapitre.

Conséquence 1 — Quand un complexe est-il nul ?

Le complexe nul

Un complexe est nul si et seulement si les deux ingrédients sont nuls :

z = 0 ⟺ Re(z) = 0 et Im(z) = 0

Attention : Re(z) = 0 tout seul signifie seulement que z est imaginaire pur — par exemple z = 5i n'est pas nul pour autant ! Il faut les deux conditions.

Conséquence 2 — Prouver que deux complexes sont différents

Un seul ingrédient qui diffère suffit

Les complexes z = 2 + 3i et w = 2 − 3i sont-ils égaux ?

Comparons ingrédient par ingrédient :

Re(z) = 2 et Re(w) = 2 → les parties réelles coïncident ✔

Im(z) = 3 et Im(w) = −3 → les parties imaginaires diffèrent ✘

Conclusion : z ≠ w. Une seule différence suffit : la règle exige que les deux ingrédients coïncident.

✏️ Exercice d'application 5 — Utiliser la règle directement

Énoncé : déterminer les réels x et y tels que (2x − 1) + (y + 3)i = 5 − 2i

Voir la solution détaillée

Étape 1 — Identifier les ingrédients. À gauche : partie réelle 2x − 1, partie imaginaire y + 3. À droite : partie réelle 5, partie imaginaire −2 (car 5 − 2i = 5 + (−2)i).

Étape 2 — Appliquer la règle (réel = réel ET imaginaire = imaginaire) :

2x − 1 = 5  et  y + 3 = −2

Étape 3 — Résoudre : 2x = 6 donc x = 3 ; y = −2 − 3 = −5

Étape 4 — Vérifier : (2×3 − 1) + (−5 + 3)i = 5 − 2i ✔

✅ Solution : x = 3 et y = −5

Notion 2 · egalite_complexes

L'identification en action

La règle d'égalité devient une méthode quand l'inconnue est complexe : on pose z = x + iy (avec x, y réels), on développe tout, puis la règle transforme l'équation complexe en système de deux équations réelles. Cette méthode s'appelle l'identification — c'est LE réflexe n°1 du chapitre.

1
Poser l'inconnue sous forme algébrique

on cherche z = x + iy, avec x et y réels

2
Développer le membre de gauche

remplacer chaque i² par −1, puis regrouper en (réel) + i(réel)

3
Identifier les parties réelles et imaginaires

grâce à : a + ib = a' + ib' ⟺ a = a' et b = b'

4
Résoudre le système, conclure, vérifier

la vérification dans l'équation de départ valide tout

🎓 Exemple complet résolu

Énoncé : déterminer les réels x et y tels que (1 + i)(x + iy) = 2 − i.

Étape 1 — Développer :

(1 + i)(x + iy) = x + iy + ix + i²y = x + iy + ix − y

= (x − y) + i(x + y)

Étape 2 — Identifier avec 2 − i = 2 + (−1)i :

x − y = 2  et  x + y = −1

Étape 3 — Résoudre : en additionnant les deux lignes : 2x = 1, donc x = 1/2 ; en reportant : 1/2 + y = −1, donc y = −3/2

Étape 4 — Vérifier : (1 + i)(1/2 − 3i/2) = 1/2 − 3i/2 + i/2 + 3/2 = 2 − i ✔

✅ Solution : z = 1/2 − (3/2)i

📝 Rédaction modèle (à recopier le jour du contrôle)

« Soit z = x + iy avec x, y ∈ ℝ. On développe : … = (…) + i(…). Or … = c + id. Par identification des parties réelles et imaginaires : … = c et … = d. On résout le système : x = …, y = …. Vérification : … ✔ »

Cette trame en 4 temps (poser → développer → identifier → vérifier) vaut la totalité des points de méthode.

Application type 1 — Résoudre (a + ib)z = c

Exemple résolu

Résoudre (1 + i)z = 4 + 2i.

Étape 1 — Poser z = x + iy : (1 + i)(x + iy) = 4 + 2i

Étape 2 — Développer : (x − y) + i(x + y) = 4 + 2i

Étape 3 — Identifier : x − y = 4 et x + y = 2

Étape 4 — Résoudre : addition : 2x = 6 → x = 3 ; puis y = 2 − 3 = −1

Vérification : (1 + i)(3 − i) = 3 − i + 3i − i² = 4 + 2i ✔

✅ Solution : z = 3 − i

Remarque : cette équation ressemble à une division z = (4 + 2i)/(1 + i) — l'identification permet de la résoudre sans aucune formule d'inverse !

Application type 2 — Décomposer sur des coefficients réels

Exemple résolu

Déterminer les réels a et b tels que a(1 + i) + b(1 − i) = 4 + 2i.

Étape 1 — Développer : a + ai + b − bi = (a + b) + i(a − b)

Étape 2 — Identifier : a + b = 4 et a − b = 2

Étape 3 — Résoudre : en additionnant : 2a = 6 → a = 3 ; en reportant : b = 4 − 3 = 1

Vérification : 3(1 + i) + 1(1 − i) = 3 + 3i + 1 − i = 4 + 2i ✔

✅ Solution : a = 3 et b = 1

Application type 3 — Reconnaître un réel pur grâce à l'égalité

Exemple résolu (paramètre réel)

Déterminer les réels x tels que z = x + (x² − 1)i soit réel pur.

Étape 1 — Écrire la condition : d'après la Notion 1, z ∈ ℝ ⟺ Im(z) = 0

Étape 2 — Appliquer : Im(z) = x² − 1, donc on résout x² − 1 = 0

Étape 3 — Résoudre : x² = 1 → x = 1 ou x = −1

Vérification : pour x = 1 : z = 1 + 0i = 1 ✔ réel. Pour x = −1 : z = −1 + 0i = −1 ✔ réel.

✅ Conclusion : z est réel pur pour x = 1 ou x = −1

Erreur classique : identifier trop tôt

Il faut d'abord regrouper tous les termes réels ensemble et tous les termes en i ensemble, puis identifier. Identifier « en vrac », terme à terme sans regrouper, est la source principale d'erreurs dans ce type d'exercice.

✏️ Exercice d'application 6 — Identification complète

Énoncé : déterminer les réels x et y tels que (x + iy)(2 − i) = 4 + 3i

Voir la solution détaillée

Étape 1 — Développer : (x + iy)(2 − i) = 2x − ix + 2iy − i²y = (2x + y) + i(2y − x)

Étape 2 — Identifier : 2x + y = 4 et −x + 2y = 3

Étape 3 — Résoudre par substitution : de la première : y = 4 − 2x. Dans la seconde : −x + 2(4 − 2x) = 3 → −x + 8 − 4x = 3 → −5x = −5 → x = 1, puis y = 4 − 2 = 2

Étape 4 — Vérifier : (1 + 2i)(2 − i) = 2 − i + 4i − 2i² = 4 + 3i ✔

✅ Solution : x = 1 et y = 2

Méthodologie

Fiches méthodes

Trois procédés à automatiser. Le jour du contrôle, ils doivent venir sans réfléchir.

📋 Méthode 1 — Mettre une expression sous forme algébrique (Notion 1)

1
Développer tous les produits et remplacer chaque i² par −1

utiliser les identités remarquables et le schéma (a + ib)(a − ib) = a² + b² si possible

2
Regrouper : les réels ensemble, les termes en i ensemble

z = (somme des réels) + i(somme des coefficients)

3
Lire Re(z) et Im(z), simplifier les fractions

ne conclure qu'une fois la forme a + ib obtenue

Application

z = (2 + i) + 3i(2 − i)

3i(2 − i) = 6i − 3i² = 3 + 6i

z = (2 + 3) + i(1 + 6) = 5 + 7i → Re(z) = 5, Im(z) = 7

📋 Méthode 2 — Identifier (équation à inconnue complexe) (Notion 2)

1
Poser z = x + iy avec x, y réels

et écrire l'équation complète

2
Développer et regrouper en (réel) + i(réel)

(ax − by) + i(ay + bx) = c + id

3
Identifier puis résoudre le système 2×2

addition/soustraction des lignes ou substitution

4
Conclure z = x + iy et vérifier

le membre de gauche doit redonner le membre de droite — vérification en 10 secondes

Application

(1 + i)z = 4 + 2i : x − y = 4 et x + y = 2 → z = 3 − i ✔

📋 Méthode 3 — Reconnaître réel pur / imaginaire pur (Notions 1 + 2)

1
Mettre d'abord z sous forme algébrique

simplifier tous les i², développer tous les produits

2
Appliquer la bonne caractérisation

réel pur ⟺ Im(z) = 0 · imaginaire pur ⟺ Re(z) = 0 · nul ⟺ les deux nuls

3
Résoudre l'équation obtenue et vérifier sur un exemple

si un paramètre x figure dans z, on obtient une condition sur x

Application

z = x + (x² − 1)i est réel pur ⟺ x² − 1 = 0 ⟺ x = ±1 ✔

🎯 QCM — Teste tes réflexes

Q1 — La partie imaginaire de z = 4 − 7i est :

A) 4i B) −7i C) −7 D) 7
Voir la réponse
C) −7. La partie imaginaire est le coefficient réel devant i — jamais un multiple de i. La réponse B est le piège classique !

Q2 — i²⁰²⁶ est égal à :

A) i B) −1 C) −i D) 1
Voir la réponse
B) −1. 2026 = 4 × 506 + 2, reste 2 → i²⁰²⁶ = i² = −1.

Q3 — a + ib = a' + ib' si et seulement si :

A) a = a' B) b = b' C) a = a' et b = b' D) a + b = a' + b'
Voir la réponse
C) a = a' ET b = b'. Les DEUX ingrédients doivent coïncider — c'est la règle fondamentale d'égalité. (D est faux : 2 + 3i ≠ 3 + 2i alors que 2 + 3 = 3 + 2 !)

Q4 — z est un réel pur si et seulement si :

A) Im(z) = 0 B) Re(z) = 0 C) z = 0 D) Re(z) = Im(z)
Voir la réponse
A) Im(z) = 0. Réel pur ⟺ partie imaginaire nulle. (B correspond à l'imaginaire pur, et C est le seul nombre à la fois réel ET imaginaire pur.)

Q5 — (2 + i)(2 − i) est :

A) un imaginaire pur B) un réel C) égal à 4 D) égal à 4 + 2i
Voir la réponse
B) un réel. (2 + i)(2 − i) = 4 − i² = 4 + 1 = 5. Le schéma (a + ib)(a − ib) = a² + b² donne toujours un réel positif !

💪 Exercices d'application (du plus facile au plus corsé)

Exercice 1 — Lire et classer (Notion 1)

Donner Re(z) et Im(z) pour z = −3 + 7i, puis classer les nombres suivants : réel pur, imaginaire pur, ou ni l'un ni l'autre : 5 · −3i · 2 + 2i · i²

Voir la solution détaillée

z = −3 + 7i : Re(z) = −3, Im(z) = 7.

5 : Im = 0 → réel pur.

−3i : Re = 0 → imaginaire pur.

2 + 2i : les deux parties sont non nulles → ni l'un ni l'autre.

i² : ⚠️ piège ! Il faut d'abord simplifier : i² = −1, donc réel pur !

Exercice 2 — Puissances de i (Notion 1)

Calculer i⁴², i¹⁰⁰, (3i)⁴

Voir la solution détaillée

i⁴² : 42 = 4 × 10 + 2 → reste 2 → i⁴² = −1

i¹⁰⁰ : 100 = 4 × 25 + 0 → reste 0 → i¹⁰⁰ = 1

(3i)⁴ : 3⁴ × i⁴ = 81 × 1 = 81

Exercice 3 — Forme algébrique (Notion 1)

Écrire sous forme algébrique : z = (2 + i)² + 3i(1 − i), puis donner Re(z) et Im(z)

Voir la solution détaillée

Premier terme (identité (a+b)²) : (2 + i)² = 4 + 4i + i² = 3 + 4i

Second terme : 3i(1 − i) = 3i − 3i² = 3 + 3i

Somme : z = (3 + 3) + i(4 + 3) = 6 + 7i

✅ z = 6 + 7i — avec Re(z) = 6 et Im(z) = 7

Exercice 4 — Égalité directe (Notion 2)

Déterminer les réels x et y tels que (3x + 2) + (y − 4)i = 8 − i

Voir la solution détaillée

Identification : à droite, 8 − i = 8 + (−1)i, donc :

3x + 2 = 8 → 3x = 6 → x = 2

y − 4 = −1 → y = 3

Vérification : (3×2 + 2) + (3 − 4)i = 8 − i ✔

✅ Solution : x = 2 et y = 3

Exercice 5 — Identification complète ★ (Notion 2)

Déterminer les réels x et y tels que (2 + i)(x + iy) = 3 + i

Voir la solution détaillée

Étape 1 — Développer : (2 + i)(x + iy) = 2x + 2iy + ix + i²y = (2x − y) + i(x + 2y)

Étape 2 — Identifier : 2x − y = 3 et x + 2y = 1

Étape 3 — Résoudre : de la première : y = 2x − 3. Dans la seconde : x + 4x − 6 = 1 → 5x = 7 → x = 7/5, puis y = 14/5 − 15/5 = −1/5

Étape 4 — Vérifier : (2 + i)(7/5 − i/5) = 14/5 − 2i/5 + 7i/5 + 1/5 = 3 + i ✔

✅ Solution : x = 7/5 et y = −1/5

Exercice 6 — Type division ★ (Notion 2)

Résoudre dans ℂ : (1 − i)z = 6 + 2i

Voir la solution détaillée

Étape 1 — Poser z = x + iy : (1 − i)(x + iy) = 6 + 2i

Étape 2 — Développer : x + iy − ix − i²y = (x + y) + i(y − x)

Étape 3 — Identifier : x + y = 6 et y − x = 2

Étape 4 — Résoudre : en additionnant : 2y = 8 → y = 4 ; puis x = 6 − 4 = 2

Vérification : (1 − i)(2 + 4i) = 2 + 4i − 2i − 4i² = 6 + 2i ✔

✅ Solution : z = 2 + 4i

Exercice 7 — Décomposition réelle ★★ (Notion 2)

Déterminer les réels a et b tels que a(2 + i) + b(1 − i) = 5

Voir la solution détaillée

Étape 1 — Développer : 2a + ai + b − bi = (2a + b) + i(a − b)

Étape 2 — Identifier avec 5 = 5 + 0i :

2a + b = 5 et a − b = 0

Étape 3 — Résoudre : la seconde donne a = b ; en reportant : 3a = 5 → a = b = 5/3

Vérification : (5/3)(2 + i) + (5/3)(1 − i) = (5/3)(3) = 5 ✔

✅ Solution : a = b = 5/3

Exercice 8 — Synthèse des deux notions ★★

Résoudre dans ℂ : z² = 2i (indice : pose z = x + iy et utilise la règle d'égalité)

Voir la solution détaillée

Étape 1 — Poser z = x + iy (x, y réels) et développer avec l'identité (a + b)² :

z² = (x + iy)² = x² + 2ixy + i²y² = (x² − y²) + 2xyi

Étape 2 — Identifier avec 2i = 0 + 2i :

x² − y² = 0  et  2xy = 2

Étape 3 — Résoudre : la première donne x² = y², donc y = x ou y = −x. La seconde donne xy = 1 > 0 : x et y sont de même signe → on garde y = x. Alors 2x² = 2 → x² = 1 → x = 1 ou x = −1, et y = x.

Étape 4 — Vérifier : (1 + i)² = 2i ✔ et (−1 − i)² = 1 + 2i + i² = 2i ✔

✅ Solutions : z = 1 + i ou z = −1 − i

Cet exercice réunit les deux notions : la forme algébrique (développer z²) et l'égalité (identifier). Le jour du contrôle, c'est ce genre de sujet qui tombe !

📌 Ce qu'il faut retenir
  • Aucun réel n'a un carré négatif : on invente i tel que i² = −1 — et toute équation x² = k (k < 0) a deux solutions opposées ±i√k… écrites ±i√(|k|) (jamais de √ sous un négatif !)
  • [forme_algebrique] Puissances de i : cycle de période 4 — i, −1, −i, 1 — et iⁿ = i^(reste de n par 4) ; somme de 4 puissances consécutives = 0
  • [forme_algebrique] Forme algébrique unique : z = a + ib avec a, b ∈ ℝ
  • [forme_algebrique] Re(z) = a et Im(z) = b sont deux réels (piège : Im(3 + 5i) = 5, pas 5i !) et z = Re(z) + i·Im(z)
  • [forme_algebrique] z réel pur ⟺ Im(z) = 0 · z imaginaire pur ⟺ Re(z) = 0 · 0 est les deux à la fois
  • [forme_algebrique] Calculs : développer puis remplacer chaque i² par −1 ; schéma précieux (a + ib)(a − ib) = a² + b²
  • [egalite_complexes] Règle : a + ib = a' + ib' ⟺ a = a' ET b = b' — justifiée par l'unicité de la forme algébrique
  • [egalite_complexes] z = 0 ⟺ Re(z) = 0 ET Im(z) = 0 — les deux conditions à la fois
  • [egalite_complexes] Une différence sur un seul ingrédient suffit pour conclure z ≠ z'
  • [egalite_complexes] L'identification (poser z = x + iy → développer → identifier → vérifier) transforme toute équation complexe en système réel — le réflexe n°1 du chapitre
